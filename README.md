# 🎧 聽日語．拼台羅（Similar sounds JP）

教師在大螢幕投影，即時組合日文假名的行（子音）、段（母音）、尾音（ん・っ）並播放日語音；學生聽音後練習拼出相同組合的**台語羅馬字**，教師再依序公布「聲母 → 韻母 → 聲調 → 台語羅馬字」，並可播放台語音。介面與操作完全比照〈[聽韓語．拼台羅](https://cyril-mingdao.github.io/Similar-sounds/)〉。

## 頁面

| 檔案 | 用途 |
|---|---|
| `index.html` | 投影頁（上課用） |
| `review.html` | 聲調審聽頁（教師審聽、修正拼音與聲調） |

## 操作

- 左側點子音（行）、母音（段）（尾音可不選）→ 自動播放日語音
  - や・ゆ・よ 接 あ行 以外的行成拗音（か行＋や＝きゃ）；わ 只能接 あ行
  - 尾音 ん 對應台語 -ng（台語借詞如歐巴桑 oo-bá-sáng），っ 對應台語入聲 -h
- 牌卡右上角 🔊 播單音：行念整行（か、き、く、け、こ），段念該假名，尾音念 ん；標題旁 ▶ 依序輪播整列，速度鈕切換 0.5～1.75 倍
- 點「聲母」「韻母」「聲調」「台語羅馬字」卡片可個別公布；公布後點台語羅馬字播放台語音
- 公布後點「聲母」「韻母」卡，播放詹宗龍老師自行錄製的聲母、韻母音檔（與〈羅馬字拼音互動遊戲〉同一批，`audio_spell/`；ung 等沒有自錄音檔的不能點）
- 簡報筆 ▶：聲母 → 韻母 → 聲調 → 答案 → 播台語音 → 隨機下一題；◀ 倒退
- 隨機出題採洗牌制：題庫每題各出一次，全部輪過才重新洗牌
- 快捷鍵：空白 播放｜S 慢速｜Enter 依序公布｜A 全部公布｜R 隨機｜T 倒數｜Esc 清空

## 題庫

只收日語與台語羅馬字**近似度 100%** 及教師審聽確認的音節（目前 27 個：あ行・さ行・な行・ま行・は行 × あ・い・え，含促音 っ；えっ 與 え 聽起來相同，教師審聽後不列入），其餘組合顯示「無近似音」並說明原因。

## 素材來源

- 日語音檔：Microsoft Edge 語音合成（ja-JP-NanamiNeural），起音淡入並統一音量（避免母音開頭爆音）
- 台語音檔（`audio_tw/`）：陽明交大台語 TTS 產生；â、ê 以 Praat 把同一發音人的 ā、ē 重塑成標準第 5 調
- 台語羅馬字依教育部《臺灣台語羅馬字拼音方案》；聲調依日語音檔實際音高（Praat 基頻分析）判定，可在審聽頁修正
